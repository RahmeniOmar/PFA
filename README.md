# PFA - Automatisation des Ventes

## Description
Script Python qui automatise l'analyse des ventes d'une entreprise e-commerce.

## Fonctionnalités
- Génération du fichier ventes.csv
- Calcul du CA Brut, CA Net et TVA
- Affichage du CA Total
- Identification du meilleur produit
- Export du fichier resultats_final.csv

## Lancer le projet

python main.py
